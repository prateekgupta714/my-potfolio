PRATEEK GUPTA — DATA ANALYST PORTFOLIO

HOW TO VIEW
1. Extract this ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.

HOW TO PUBLISH FOR FREE WITH GITHUB PAGES
1. Sign in to GitHub and create a new public repository (for example: prateek-portfolio).
2. Upload index.html and Prateek_Gupta_Data_Analyst_Resume.docx to the repository root.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
5. After GitHub Pages finishes publishing, use the website URL shown in Settings → Pages.
